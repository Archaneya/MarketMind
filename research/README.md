# MarketMind ML Research Evidence

This folder records why MarketMind uses its market-regime clustering algorithm. It is a set of reproducible Python experiments and evidence files, **not a dashboard**.

## Run the experiment

From the MarketMind project root, in the same Python environment as the application:

```bash
python -m research.run_comparison
```

The script generates synthetic market data using the existing `MarketSimulator`, computes the same seven features used by the live regime detector, and compares K-Means, Gaussian Mixture Model, Agglomerative Clustering and DBSCAN.

## Evidence generated

- `results/model_metrics_by_seed.csv` — every model's held-out metrics for every seed.
- `results/model_metrics_summary.csv` — mean and standard deviation across seeds.
- `results/experiment_metadata.json` — seeds, settings, preprocessing and selection rule.
- `results/final_model_selection.md` — readable methodology, results, decision and limitations.

## Evaluation design

- Chronological 70/30 train/test split for each seed.
- StandardScaler is fitted only on training features.
- The simulator's hidden regime is not a model input. It is used only as an evaluation reference.
- ARI and NMI compare predicted clusters with simulator regimes without requiring cluster-ID alignment.
- Silhouette, Davies-Bouldin and Calinski-Harabasz evaluate geometric cluster structure.
- Fit and prediction times are recorded.

## Important implementation differences

K-Means and GMM have native prediction methods. Agglomerative Clustering does not; for held-out evaluation this experiment uses a nearest-training-cluster-centroid proxy. DBSCAN also has no native prediction method; the experiment assigns a held-out point to its nearest training core point only if it falls within `eps`, otherwise it is marked as noise. These approximations are explicitly identified in the CSV and report.

For DBSCAN, internal geometric metrics exclude noise points, while the noise percentage is reported separately. ARI and NMI include the noise label as a cluster label.

## Model-selection rule

The script selects the algorithm with the highest mean held-out ARI across the declared seeds; mean held-out NMI is the tie-breaker. This rule is declared before the experiment. It does not guarantee universal superiority.

## Relationship to production

This research folder does not automatically change `ml/regime_detection.py`. After reviewing the results, a developer must deliberately decide whether to change the production detector. A synthetic simulator benchmark alone is not sufficient evidence to deploy a different model on real NIFTY data.

## Limitations

The benchmark is generated by MarketMind's own synthetic regime-switching simulator. It is useful for controlled experimentation because the simulator provides hidden regime labels, but it cannot establish real-market accuracy, profitability, or robustness to actual market microstructure. Validate on real historical data before making claims about live-market performance.
